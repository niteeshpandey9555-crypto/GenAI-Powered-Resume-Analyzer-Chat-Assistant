# AI Resume Analyzer

AI Resume Analyzer is an NLP and Generative AI based application that automatically extracts structured information from resumes.  
The project uses Large Language Models (Google Gemini) with LangChain to analyze resumes in PDF, DOCX, and TXT formats.

---

## 🚀 Features
- Upload resumes in PDF, DOCX, or TXT format
- Extract key information such as:
  - Name
  - Email
  - Phone Number
  - Skills
  - Education
  - Experience
  - Projects
- Structured JSON output
- Simple and interactive Streamlit UI
- Powered by Generative AI (Google Gemini)

---

## 🧠 Project Type
- Domain: NLP + Generative AI
- Level: Intermediate
- Use Case: HR Tech / Resume Screening Automation

---

## 🛠 Tech Stack
- Python
- Streamlit
- LangChain
- Google Gemini LLM
- NLP
- PyPDF / python-docx
